Everything you need to know about FuzzBot, its commands, and its features.

🤖 About FuzzBot

FuzzBot is a custom Discord bot created for the FantasticFuzz community.

FuzzBot provides useful moderation tools, custom embeds, slash commands, and other features for Discord communities.

🚀 Getting Started

To start using FuzzBot, invite the bot to your Discord server using the Invite Bot button.

Once FuzzBot is in your server, type / in a Discord channel to see its slash commands.

⚡ Commands

/ping

Check Bot Status

Checks whether FuzzBot is online and responding.

/createembed

Create an Embed

Creates a custom Discord embed with your chosen title, message, and color.

/aboutbot

About FuzzBot

Displays information about FuzzBot, including its creator and version.

/warn

Warn a Member

Sends a warning to a server member.

/ban

Ban a Member

Bans a member from the Discord server.

/kick

Kick a Member

Removes a member from the Discord server.

/timeout

Timeout a Member

Temporarily prevents a member from interacting in the server.

/mute

Mute a Member

Mutes a member to prevent them from chatting.
